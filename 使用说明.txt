桌面框 · 使用说明
======================================================================

一个停在桌面上的小窗口，把 D / E / F 盘里常用的几个文件夹钉在桌面层，
不用每次都开资源管理器一层层点进去。

  · 待在「桌面之上、其它窗口之下」：不挡你正在用的软件，又随时能看到
  · 文件都留在原来的盘里，只是列出来，不复制、不占 C 盘空间
  · 纯 PowerShell + 系统自带控件：不用安装、不用管理员权限、不联网


----------------------------------------------------------------------
一、开始使用（三步）
----------------------------------------------------------------------

1) 把整个「桌面框」文件夹解压到任意位置，比如  D:\桌面框
   （别放进 C:\Program Files，那里普通权限改不了配置文件）

2) 双击文件夹里的「启动桌面框.vbs」

3) 第一次启动会自动弹出设置窗口：
   点「添加目录」→ 选一个文件夹 → 「保存并关闭」。
   可以加多个，每个目录在框里是一块独立的分区。

想把图标放到桌面上（可选）：
   双击 tools\install.bat，会在桌面创建一个「桌面框」快捷方式。
   不建也行 —— 直接双击 vbs 一样用。


----------------------------------------------------------------------
二、右上角的按钮（从右往左）
----------------------------------------------------------------------

  ×    退出程序
  —    收起 / 展开（收起后只剩一条标题栏，再点一下还原）
  ⟳    刷新当前目录
  ⚙    设置：来源目录、背景不透明度、开机自动启动
  固   固定：锁住窗口位置，防止手滑把框拖歪
       固定之后仍然可以拉边改窗口大小、拖分区横条改分区高度
  ⊟    一键收放：把所有分区的内容一起收起来，只剩块头
       收起之后按钮变成 ⊞，再点一下全部展开


----------------------------------------------------------------------
三、能做的操作
----------------------------------------------------------------------

  · 单击选中，双击打开（文件夹则进入，框顶部会出现返回箭头）
  · 右键菜单和资源管理器一样：
    打开 / 打开方式 / 剪切 / 复制 / 粘贴 / 重命名 / 删除（进回收站）/
    新建文件夹 / 刷新 / 复制文件地址 / 属性 / 共享 / 更多选项
    （WinRAR、360压缩、批量重命名等第三方菜单项会自动出现在「更多选项」里）
  · 把文件拖到别的程序（微信、浏览器、压缩软件…）= 复制过去
  · 从资源管理器把文件 / 文件夹拖进框 = 复制到该分区所在的目录
  · 鼠标停在文件上就能滚轮（列表滚到底会接着滚整个框）
  · 拖分区之间那条细横线 = 改这个分区的高度，松手记住，重开还原
  · 点分区标题 = 折叠 / 展开这个分区
  · 按住分区标题栏上下拖 = 把这个目录挪到你想要的位置（松手就记住）
  · 点标题栏的 ⊟ / ⊞ = 所有分区一起收起 / 展开
  · 拉窗口的四边 / 四角 = 改窗口大小
  · 选中一个文件后，左下角显示它的大小和修改时间

选中文件后的快捷键：

  Enter             打开
  Ctrl+C / Ctrl+X   复制 / 剪切（可以直接粘到资源管理器里）
  Ctrl+V            粘贴到当前文件夹
  F2                重命名
  Delete            删除（进回收站，不会彻底删）
  Ctrl+Shift+C      复制完整路径
  Alt+Enter         属性


----------------------------------------------------------------------
四、开机自动启动
----------------------------------------------------------------------

点 ⚙ → 勾选「开机自动启动（恢复上次关闭时的状态）」→ 保存并关闭。

下次登录 Windows 会自动起来，并按上次关闭时的样子恢复：
窗口位置、窗口大小、背景透明度、分区列表、固定状态、各分区高度。

关闭它：同样进 ⚙ 取消勾选即可。它只在「当前用户」的启动项里加一条，
不需要管理员权限，也不改变系统其它设置。

以后把「桌面框」文件夹挪到别处不用管：程序启动时会自动把启动项里的
路径改成新位置。


----------------------------------------------------------------------
五、备份 / 换电脑
----------------------------------------------------------------------

所有设置都在 app\config.json 里（来源目录、窗口位置大小、透明度、开机自启等）。
把整个文件夹拷走，设置跟着走；只想搬设置，拷这一个文件就行。


----------------------------------------------------------------------
六、常见问题
----------------------------------------------------------------------

Q：双击 vbs 没反应，或者弹「Windows 已保护你的电脑」
A：从网上下载的压缩包会被 Windows 打标记。右键这个压缩包 → 属性 →
   勾选「解除锁定」→ 确定，然后重新解压、再双击。
   （已经解压出来的，也可以对 vbs 做同样操作）

Q：双击之后什么都没出现
A：程序是单实例的。已经在运行时，再双击一次只是让窗口「显示 / 隐藏」。
   去屏幕右下角托盘看看有没有一个小图标。

Q：提示找不到 app\desktop_box.ps1
A：文件没解压全。整个「桌面框」文件夹要一起拷，不能只拿 vbs 一个文件。

Q：会不会占 C 盘空间？会不会动我的文件？
A：都不会。程序只是把目录列出来，新建 / 删除 / 重新命名都是在原盘原位置进行的。

Q：某个分区里文件太多
A：所有条目都会列出来（隐藏文件是否显示可在设置里选）；分区默认按内容
   自适应高度、最多露出 16 行，其余在分区内部滚动；分区高度也能直接拖。

Q：怎么彻底退出
A：点右上角的 ×；或右下角托盘图标右键 → 退出。

Q：出问题怎么排查
A：双击 tools\check.ps1（或右键 → 使用 PowerShell 运行），它会逐项列出环境问题。
   启动就崩的原因会写在 app\error.log 里。


----------------------------------------------------------------------
七、运行环境
----------------------------------------------------------------------

  · Windows 10 / 11（自带 PowerShell 5.1 即可，不用另外装 .NET 或运行库）
  · 不需要管理员权限
  · 不联网
  · 只在两个地方写入：本文件夹里的 app\config.json，以及（你自己勾选时）
    当前用户的启动项 HKCU\Software\Microsoft\Windows\CurrentVersion\Run


----------------------------------------------------------------------
八、文件夹里都有什么
----------------------------------------------------------------------

  启动桌面框.vbs        双击这个启动（它只是转手去跑下面那个 ps1，不弹黑框）
  app\desktop_box.ps1   程序本体（全部逻辑都在这一个文件里）
  app\config.json       你的设置，程序会自动读写
  tools\install.bat     可选：在桌面创建快捷方式
  tools\check.ps1       可选：环境自检，出问题时用
  tools\make_box.ps1    早期备选方案（在桌面建真实文件夹 + 目录联接）
  tools\run_make_box.bat  上面那个的启动器
                        ※ 备选方案和本程序二选一，别同时用，两者都会在桌面
                          用「桌面框」这个名字
